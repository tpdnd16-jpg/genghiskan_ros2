# 1. NAS 유지보수 자동화 로봇팔

## 1) 개요

NAS의 저장장치 이상을 감지하고, 하드웨어 문제가 발생한 경우 로봇팔이 기존 HDD를 제거하고 신규 HDD로 교체하는 유지보수 자동화 시스템입니다. NAS별 HDD 위치와 예비 부품의 보관 위치를 데이터베이스로 관리하여 하나의 로봇팔이 여러 장비의 유지보수를 담당하는 것을 목표로 합니다.

## 2) 문제

- HDD는 장기간 사용하면 고장이나 성능 저하가 발생할 수 있음.
- HDD 교체 시 관리자가 직접 장비를 확인하고 부품을 교체해야 함.
- 여러 대의 NAS를 운영하는 사업장은 반복적인 유지보수 작업에 인력이 소모됨.
- 고장 난 HDD를 잘못 제거하거나 교체 절차를 잘못 수행하면 데이터 손실 위험이 있음.

## 3) 아이디어

NAS 관리 프로그램에서 HDD 이상 상태를 전달받고, 데이터베이스에 저장된 위치 정보를 기반으로 로봇팔이 자동으로 HDD를 교체하는 시스템을 구축합니다.

- NAS별 HDD 장착 위치 관리
- HDD 이상 상태 및 교체 대상 관리
- 신규 HDD 재고와 보관 위치 관리
- 로봇팔을 이용한 기존 HDD 제거 및 신규 HDD 장착
- 교체 이력 및 재고 정보 갱신

## 4) 동작

1. NAS 관리 프로그램에서 특정 HDD의 이상 상태를 감지함.
2. 데이터베이스에서 교체 대상 HDD와 신규 HDD의 위치를 조회함.
3. 로봇팔이 NAS 모형에서 기존 HDD를 제거함.
4. 제거한 HDD를 불량품 보관 공간에 배치함.
5. 보관 공간에서 신규 HDD를 가져와 NAS 모형에 삽입함.
6. PC 프로그램에서 HDD 교체 완료 및 재고 정보를 갱신함.

## 5) 시연 구성 및 방법

- NAS 모형: HDD 슬롯을 표현한 직육면체 상자 1개
- HDD 모형: 실제 HDD와 비슷한 크기의 직사각형 소품 5개
- 보관 공간: 신규 HDD와 불량 HDD를 구분하여 놓는 간단한 거치대
- 로봇팔: 두산로보틱스 협동로봇과 그리퍼 활용

시연 시나리오

1. PC 프로그램에서 특정 HDD에 고장 표시
2. 로봇팔이 해당 HDD를 찾아 제거
3. 기존 HDD를 불량품 보관 공간에 배치
4. 신규 HDD를 가져와 기존 슬롯에 삽입
5. PC 프로그램에서 교체 완료 및 재고 상태 갱신

## 6) 기대효과

- HDD 교체 과정에서 발생하는 반복적인 수작업 감소
- 여러 대의 NAS를 하나의 로봇팔로 통합 관리
- HDD 재고 및 장착 위치의 체계적인 관리
- 유지보수 작업 이력 자동 기록
- 소규모 서버실의 유지보수 효율 향상

# 2. 소규모 3D 프린팅 팜 자동화 로봇팔

## 1) 개요

여러 대의 3D 프린터를 운영하는 소규모 출력 사업장에서 출력판 교체 작업을 자동화하는 로봇팔 시스템입니다. 하나의 로봇팔이 여러 프린터의 출력 완료 상태를 확인하고 출력판을 교체하여 작업자의 개입을 최소화하는 것을 목표로 합니다.

## 2) 문제

- 3D 프린터는 출력이 완료될 때마다 출력물을 회수하고 다음 작업을 준비해야 함.
- 출력판 교체와 출력물 회수 과정에서 반복적인 수작업이 발생함.
- 여러 대의 프린터를 운영하면 출력 완료 시점이 달라 관리 부담이 증가함.
- 출력판 교체가 지연되면 다음 출력 작업을 시작하지 못해 프린터 가동률이 낮아짐.

## 3) 아이디어

프린터별 위치와 출력판의 보관 위치를 데이터베이스로 관리하고, 출력 완료 상태를 전달받으면 로봇팔이 해당 프린터의 출력판을 교체하는 시스템을 구축합니다.

- 프린터별 위치 및 작업 상태 관리
- 출력판별 사용 상태와 보관 위치 관리
- 출력 완료 상태에 따른 작업 대상 선정
- 로봇팔을 이용한 출력판 제거 및 교체
- 출력판 교체 후 다음 작업 준비 및 상태 갱신

## 4) 동작

1. 프린터 소프트웨어에서 출력 완료 상태를 전달받음.
2. 데이터베이스에서 출력이 완료된 프린터와 사용 중인 출력판 정보를 조회함.
3. 로봇팔이 해당 프린터에서 기존 출력판을 제거함.
4. 기존 출력판을 지정된 보관 공간에 배치함.
5. 보관 공간에서 새로운 출력판을 가져와 프린터에 장착함.
6. PC 프로그램에서 출력판 상태를 갱신하고 다음 작업을 준비함.

## 5) 시연 구성 및 방법

- 프린터 모형: 3D 프린터 외형을 간단하게 표현한 모형 2개
- 출력판 모형: 직사각형 판 형태의 소품 4개
- 보관 공간: 출력판을 올려놓는 간단한 거치대
- 로봇팔: 두산로보틱스 협동로봇과 전용 그리퍼 활용

시연 시나리오

1. PC 프로그램에서 특정 프린터의 출력 완료 표시
2. 로봇팔이 해당 프린터로 이동
3. 기존 출력판을 집어서 제거
4. 기존 출력판을 보관 공간에 배치
5. 새로운 출력판을 가져와 프린터에 장착
6. PC 프로그램에서 출력판 상태를 갱신하고 다음 출력 준비 완료 표시

## 6) 기대효과

- 출력판 교체에 필요한 반복적인 수작업 감소
- 하나의 로봇팔로 여러 대의 프린터 통합 관리
- 프린터 유휴 시간 감소 및 가동률 향상
- 출력판의 사용 상태와 보관 위치 관리
- 소규모 3D 프린팅 사업장의 무인 운영 환경 구축

## 3. 프로젝트 공통 구현 요소

| 구분    | 구현 내용                      |
| ----- | -------------------------- |
| 로봇 제어 | 두산로보틱스 로봇팔의 이동 및 그리퍼 제어    |
| 위치 관리 | 작업 대상과 보관 장소의 좌표 데이터베이스 관리 |
| 작업 관리 | PC 프로그램을 통한 작업 대상 및 명령 관리  |
| 상태 관리 | 작업 전후 부품 및 출력판 상태 갱신       |
| 시연 환경 | 실제 장비 대신 외형만 유사한 모형과 소품 활용 |

공통 핵심: 데이터베이스에서 작업 대상과 위치를 조회하고, 두산로보틱스 로봇팔이 해당 좌표로 이동하여 반복 작업을 자동으로 수행하는 시스템을 구현함.
